## [0.1.0] - 2026-10-08

### Added

- Управление стратегиями обхода блокировок (.bat-файлы): сканирование папки, запуск, остановка
- Перехват stdout/stderr в реальном времени, журнал с виртуализацией (10 000+ строк)
- Фильтрация логов по уровню, источнику и стратегии, поиск с подсветкой, экспорт в файл
- Игровой режим отображения стратегий («карты»): 3D-tilt, flip, glow, редкость Common / Rare / Epic / Legendary
- Dashboard: hero-панель, статус подключения, данные соединения (IP, страна, провайдер), мини-график пинга
- Визуализатор трафика в реальном времени, монитор счётчиков и пинга
- Страница логов с автоскроллом, экспортом и диалогом очистки
- Страница настроек с 8 секциями, импорт/экспорт настроек, сброс секций
- Переключение bat ↔ VPN (WireGuard / AmneziaWG), импорт .conf, kill switch через Windows Firewall
- Внедрение доменов Outlast Trials в конфиги стратегий
- Системный трей с 5 состояниями иконки и динамическим меню, нативные уведомления Windows
- Встроенные ресурсы: автоматическая распаковка при первом запуске, проверка целостности, умное обновление
- Обновление стратегий через GitHub Releases: проверка, скачивание, установка, откат, бэкапы
- Кастомный NSIS-установщик с тёмной темой и русским/английским языками
- Постобработка: bloom, vignette, film grain, scanlines, chromatic aberration, motion blur
- Адаптивность: от 800×600 до 2560×1440, автосворачивание сайдбара, корректный DPI и мультимонитор
- Полноэкранный режим (F11), локализация RU/EN, тема и плотность интерфейса

### Changed

- Оптимизация: 60 FPS, холодный старт < 1.5 с, ленивая загрузка страниц, мемоизация виджетов
- Логи пишутся пачками в idle и не блокируют интерфейс
- Пинг не выполняется в свёрнутом окне, canvas перестраивается при смене DPI
- Трафик сглаживается EWMA, шкала растёт с запасом и затухает плавно

### Fixed

- Вложенная кнопка бейджа обновлений внутри кнопки навигации (невалидный HTML)
- Автосворачивание сайдбара при старте на узком экране (StrictMode дважды переключал состояние)
- Форматирование размеров: «3 ГБ» вместо «3.00 ГБ», лишний перевод строки в экспорте списков
- Перенос окна между мониторами с разным масштабом, обрезка длинных путей в интерфейсе

### Security

- Валидация всех входных данных: Zod-схемы на границе IPC, проверка ответов команд
- Защита от path traversal, command injection и подмены расширений
- Content Security Policy, минимальный набор Tauri capabilities (31 разрешение), `devtools: false`
- Rate limiting критичных команд, отдельный `security.log` с ротацией, редактирование секретов в логах
- Проверка целостности встроенных ресурсов и обновлений по SHA-256
- Внешние ссылки открываются только через разрешённый список URL
- Аудит зависимостей: `cargo audit`, `pnpm audit` — без уязвимостей
