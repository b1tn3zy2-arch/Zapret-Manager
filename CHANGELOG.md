## [1.0.2] - 2026-11-23

### Changed (оптимизация без изменения публичного API)

- Построчно задокументированы все исходные файлы: 469 файлов, ~107 тыс. поясняющих комментариев. Комментарии не попадают в релизный бандл (проверено по сборке).
- `PingSparkline.tsx`: частота перерисовки canvas ограничена 15 кадр/с и приостановлена в скрытой вкладке. Раньше 4 экземпляра графика перерисовывались 60 раз в секунду при обновлении данных раз в 2 с.
- `format.ts` / `HighlightText.tsx`: регулярные выражения поиска кэшируются, проверка совпадения больше не меняет `lastIndex`. Снято по `RegExp` на каждую видимую строку лога.
- `storage.ts`: путь к файлу настроек собирается из уже полученного каталога данных — устранён повторный IPC-вызов `appDataDir()` при каждой записи.
- `payment.rs`: регулярное выражение ссылки на подписку компилируется один раз через `LazyLock`, а не при каждом опросе окна оплаты.
- `log_analyzer.rs`: читается только хвост лога (`seek` вместо полного `read`), а не весь мегабайтный файл.
- `game_sources_system.rs`: нормализация имени выполняется один раз вместо повтора на каждое стоп-слово.
- Обновлены манифесты версии 1.0.1 → 1.0.2 (patch: поведение и API не менялись).

### Validation

- `tsc --noEmit`, ESLint, Prettier, i18n-check, CSS-contract, release-metadata — без ошибок.
- Vitest: 46/46 файлов, 490/490 тестов; `cargo check`, `cargo fmt --check`, `cargo test`, `cargo clippy -D warnings` — без ошибок.
- Vite build: 3 344 модуля, ~27,2 с (baseline ~28,9 с); размер бандла 2,15 МБ — без изменения.

## [1.0.1] - 2026-11-21

### Changed

- Ускорен поиск переводов: словари `ru`/`en` один раз разворачиваются в плоские карты, а переводчики кешируются. Микробенчмарк на 1 000 000 поисков: 467,1 мс → 7,7 мс (ускорение ×60,9).
- Подготовлена релизная сборка 1.0.1: MSI, NSIS и portable-архив.

### Fixed

- Синхронизированы версии в `package.json`, `tauri.conf.json`, `Cargo.toml` и `APP_VERSION`.
- Добавлены контрольные суммы SHA-256 для релизных артефактов.
