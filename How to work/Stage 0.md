ЗАДАЧИ:

1. BRAND ESSENCE: не требуется (по запросу пользователя).

2. SIGNATURE MOMENT (два элемента):
   • Анимированная игра в стратегий — визуализация, где каждая
     стратегия (.bat) представлена как «карта» с характеристиками:
     какие сервисы обходит (Discord, YouTube, Outlast Trials),
     скорость, стабильность. Пользователь «играет» — выбирает
     карту, запускает, видит результат.
   • Красивый визуализатор трафика — живой график в реальном
     времени: входящий/исходящий трафик, пинг до сервисов,
     состояние DPI-обхода. Должен выглядеть как «пульт
     управления космическим кораблём».

3. ЦЕЛЕВАЯ АУДИТОРИЯ: обычный пользователь (не технарь).
   • Простой UI: одна кнопка «Подключить»
   • Но с «вау»-эффектом: анимации, стекло, неон
   • Технические детали — в скрытой панели «Для продвинутых»

4. OUTLAST TRIALS — что это:
   • Это игра (Outlast Trials), многопользовательский хоррор.
   • Использует BattlEye античит [citation:1][citation:16].
   • Для работы игры нужен доступ к серверам (домены/IP).
   • ЗАДАЧА: добавить домены/IP Outlast Trials в конфиги
     стратегий (list-general.txt, ipset-all.txt и т.д.).
   • ЕСЛИ НЕ ЗНАЕШЬ ТОЧНЫЕ ДОМЕНЫ — задай вопрос пользователю
     или предложи найти их через сетевой мониторинг.

5. РАБОЧАЯ ПРОВЕРКА ОБНОВЛЕНИЙ через GitHub:
   • Приложение периодически проверяет GitHub Releases
     репозитория zapret-discord-youtube.
   • Если вышла новая версия — уведомляет и предлагает обновиться.
   • Скачивает и распаковывает автоматически.
   • Версия сравнивается по семантическому версионированию
     (semver) [citation:5][citation:13].

6. РАБОЧИЕ НАСТРОЙКИ (обязательно):
   • Папка со стратегиями (выбор через диалог)
   • Автозапуск при старте Windows
   • Сворачивать в трей при закрытии
   • Тема (тёмная/светлая/авто)
   • Язык (RU/EN)
   • Outlast Trials: включить/выключить, список доменов
   • VPN: настройки подключения (Amnezia/WireGuard)
   • Проверка обновлений: вкл/выкл, частота
   • Логирование: уровень детализации

7. ПЕРЕКЛЮЧЕНИЕ bat ↔ VPN:
   • Концепция Amnezia VPN: self-hosted, open-source,
     мультипротокольный клиент [citation:7].
   • Либо концепция хапа: WireGuard/OpenVPN.
   • Функция: одним переключателем сменить режим
     «DPI-обход» (bat) на «VPN-туннель» и обратно.
   • ВАЖНО: при переключении bat-стратегия останавливается,
     VPN-клиент запускается (и наоборот).
   • UI: большой тумблер в Dashboard с анимацией.

8. СПИСОК КЛЮЧЕВЫХ ФУНКЦИЙ MVP (10–12):
   1. Сканирование папки с .bat
   2. Отображение стратегий в виде «карт» (игра)
   3. Запуск .bat с правами админа
   4. Просмотр логов в реальном времени
   5. Визуализатор трафика (график)
   6. Проверка обновлений через GitHub
   7. Автообновление стратегий
   8. Настройки (рабочие)
   9. Переключение bat ↔ VPN
   10. Внедрение Outlast Trials в конфиги
   11. Автозапуск выбранной стратегии
   12. Статус-индикатор (Connected/Disconnected)

9. КРИТЕРИИ УСПЕХА:
   • FPS ≥ 60 (десктоп), ≥ 30 (ноутбук)
   • Холодный старт < 2 сек
   • RAM < 200 MB
   • Нет утечек памяти
   • Нет багов в консоли
   • UI уровня Awwwards
   • Работает на Windows 10/11
   • Обновления с GitHub работают
   • Переключение bat ↔ VPN работает
