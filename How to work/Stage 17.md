# ЭТАП 17: КАСТОМНЫЙ УСТАНОВЩИК

═══════════════════════════════════════════════════════════════════════
ЭТАП 17: КАСТОМНЫЙ УСТАНОВЩИК
ПРОЕКТ: Zapret Manager — десктопное приложение для управления
стратегиями обхода блокировок (Discord, YouTube, Outlast Trials)
═══════════════════════════════════════════════════════════════════════

🎯 ЦЕЛЬ ЭТАПА

Создать профессиональный установщик на базе NSIS с кастомным
оформлением: тёмная тема в стиле приложения, собственные страницы
(приветствие, лицензия, выбор папки, опции установки), кастомные
иконки, прогресс-бар с анимациями, финальный экран с опцией
запуска приложения и создания ярлыков. Установщик должен выглядеть
и ощущаться как часть премиум-продукта, а не как стандартный
«Next → Next → Finish» из 90-х.

После этого этапа пользователь сможет:
  • Скачать один .exe-файл (ZapretManager_0.1.0_x64-setup.exe)
    размером 30–50 MB
  • Запустить установщик — увидеть красивое тёмное окно с
    логотипом, версией и описанием
  • Пройти через интуитивные страницы:
    - Приветствие (описание продукта, ключевые возможности)
    - Лицензия (показать и принять)
    - Выбор папки установки
    - Опции (ярлыки, автозапуск, ассоциация, установить для
      всех пользователей / текущего)
    - Прогресс установки (с детальными логами)
    - Финал (запуск приложения, создание ярлыков)
  • Установка занимает 5–15 секунд на SSD
  • Установщик корректно работает на Windows 10 и 11
  • Удаление через «Программы и компоненты» работает чисто,
    с опцией удалить пользовательские данные

Это последний этап перед полировкой и оптимизацией. После
него приложение готово к публикации в его текущем виде.

🏗️ ЧАСТЬ 1: АРХИТЕКТУРНЫЕ РЕШЕНИЯ (обосновать перед реализацией)
═══════════════════════════════════════════════════════════════════════

【 РЕШЕНИЕ 1: NSIS вместо WiX / MSI 】

ОБОСНУЙ:
  • NSIS — самый популярный установщик для Windows-утилит
  • Tauri 2 имеет встроенную поддержку NSIS
  • Кастомные страницы (custom pages) — нативно
  • Маленький размер (150 KB базовый + наши ресурсы)
  • Поддержка Unicode (кириллица работает без бубнов)
  • Поддержка installMode: currentUser (без UAC) или
    perMachine (с UAC)
  • Кастомизация: MUI2 (Modern UI 2) с кастомными bitmap'ами

ПОЧЕМУ НЕ WIX / MSI:
  • WiX сложнее в настройке
  • MSI не поддерживает installMode: currentUser так же
    изящно
  • Меньше возможностей для визуальной кастомизации
  • Больше boilerplate XML

ПОЧЕМУ НЕ MSIX:
  • Требует подписи сертификатом (иначе SmartScreen блокирует)
  • Сложная разработка
  • Не подходит для открытого Open Source проекта

ПОЧЕМУ НЕ INNO SETUP:
  • Tauri не имеет встроенной поддержки Inno
  • Потребовал бы отдельный pipeline

【 РЕШЕНИЕ 2: installMode — both (пользователь выбирает) 】

ОБОСНУЙ:
  • Tauri 2 NSIS поддерживает три режима:
    - "currentUser" — установка в %LOCALAPPDATA%, без UAC
    - "perMachine" — установка в Program Files, с UAC
    - "both" — пользователь выбирает при установке
  • Режим "both" — лучший UX: пользователь сам решает
  • По умолчанию — currentUser (без UAC, быстрее)
  • В настройках установщика есть Radio: «Для меня» /
    «Для всех пользователей»

ПОЧЕМУ НЕ ТОЛЬКО CURRENTUSER:
  • Некоторые пользователи хотят установку для всех
    (семейный компьютер)
  • Program Files выглядит «серьёзнее» для некоторых

ПОЧЕМУ НЕ ТОЛЬКО PERMACHINE:
  • Требует UAC → лишний шаг
  • Не работает для пользователей без admin-прав

【 РЕШЕНИЕ 3: Кастомные страницы через NSIS MUI2 + Tauri hooks 】

ОБОСНУЙ:
  • Tauri позволяет вставить в установщик свои .nsh-скрипты
    (NSIS Header files)
  • Через installerHooks в tauri.conf.json:
    - NSIS_HOOK_PREINSTALL — до установки
    - NSIS_HOOK_POSTINSTALL — после установки
    - NSIS_HOOK_PREUNINSTALL — до удаления
    - NSIS_HOOK_POSTUNINSTALL — после удаления
  • Кастомные страницы добавляются через
    !insertmacro MUI_PAGE_*
  • Дизайн — через MUI2 variables (цвета, шрифты, bitmap'ы)

КАСТОМНЫЕ СТРАНИЦЫ:
  1. Welcome — приветствие с иконкой и описанием
  2. License — лицензия (EULA)
  3. Components — выбор компонентов (ярлыки, автозапуск)
  4. Directory — выбор папки
  5. Install — прогресс
  6. Finish — финал с опциями запуска

ПОЧЕМУ НЕ СТАНДАРТНЫЙ WELCOME NSIS:
  • Скучный, серый, без брендинга
  • Не отражает «премиум» продукта

【 РЕШЕНИЕ 4: Кастомные bitmap'ы для NSIS — тёмная тема 】

ОБОСНУЙ:
  • NSIS MUI2 поддерживает:
    - MUI_WELCOMEFINISHPAGE_BITMAP (164x314 px)
    - MUI_HEADERIMAGE_BITMAP (150x57 px)
    - MUI_ICON / MUI_UNICON
  • Заменяем стандартные bitmap'ы на кастомные:
    - welcome.bmp — тёмный фон с логотипом Zapret Manager
    - header.bmp — тонкая полоска с логотипом и градиентом
    - icon.ico — иконка приложения
  • Дизайн в стиле приложения (#0a0a0f, #00ff88)

ПОЧЕМУ НЕ ОСТАВИТЬ СТАНДАРТНЫЕ:
  • Стандартные — светлые, не соответствуют тёмной теме
  • Пользователь видит «разрыв» между установщиком и
    приложением

ПОЧЕМУ НЕ КАСТОМНЫЙ UI ЧЕРЕЗ ELECTRON-ПОДОБНОЕ:
  • Установщик должен быть лёгким и быстрым
  • NSIS с bitmap'ами — идеальный баланс

【 РЕШЕНИЕ 5: Опции установки — Radio + Checkbox на странице Components 】

ОБОСНУЙ:
  • Страница Components в NSIS MUI2 позволяет:
    - Radio buttons (install mode)
    - Checkboxes (опции)
  • Опции:
    - ✓ Создать ярлык на рабочем столе
    - ✓ Создать ярлык в меню «Пуск»
    - ✓ Запускать при старте Windows (автозапуск)
    - ✓ Ассоциировать .bat файлы (опционально, спорно)
    - ✓ Запустить Zapret Manager после установки
  • Сохраняются в реестр для последующего удаления

ПОЧЕМУ НЕ ОТДЕЛЬНЫЕ СТРАНИЦЫ ДЛЯ КАЖДОЙ ОПЦИИ:
  • 5 страниц = раздражает
  • Одна страница с чекбоксами — быстро

ПОЧЕМУ АССОЦИАЦИЯ .BAT СПОРНА:
  • Может конфликтовать с другими приложениями
  • Только для «power users» — выключена по умолчанию
  • Реализуется через реестр

【 РЕШЕНИЕ 6: Прогресс-бар установки с детальными шагами 】

ОБОСНУЙ:
  • Стандартный NSIS progress bar показывает только процент
  • Кастомный — показывает этапы:
    - «Извлечение ресурсов...»
    - «Установка zapret...»
    - «Копирование стратегий...»
    - «Создание ярлыков...»
    - «Регистрация в реестре...»
  • Реализация: NSIS DetailPrint + кастомный DetailPrint
    hook
  • Отображение в окне установки под прогресс-баром

ПОЧЕМУ КАСТОМНЫЙ:
  • Пользователь видит, что происходит
  • Уверенность, что установка не зависла

【 РЕШЕНИЕ 7: Проверка требований перед установкой 】

ОБОСНУЙ:
  • Windows 10 1809+ (для WebView2)
  • Архитектура: x64
  • Свободное место: 200 MB
  • WebView2 — обычно уже установлен, но проверяем
  • Если WebView2 нет — предложить установить
    (в Tauri NSIS это уже встроено через
    webviewInstallMode)

ПРОВЕРКИ В NSIS:
  • ${If} ${AtLeastWin10}
  • Проверка свободного места через GetDiskFreeSpaceEx
  • Проверка WebView2 через реестр

ПОЧЕМУ ВАЖНО:
  • Не даём установить на Windows 7 (не работает)
  • Понятное сообщение вместо «приложение не запускается»

【 РЕШЕНИЕ 8: Кастомный финальный экран с двумя опциями 】

ОБОСНУЙ:
  • Стандартный Finish — просто «Готово»
  • Кастомный:
    - Заголовок: «Установка завершена!»
    - Иконка приложения (большая)
    - Две галочки:
      - ✓ Запустить Zapret Manager
      - ✓ Открыть папку с настройками
    - Кнопка «Завершить» (primary, зелёная)
  • Стиль — как у приложения (тёмный фон)

ПОЧЕМУ ДВЕ ОПЦИИ:
  • Запуск — стандарт
  • Открыть папку — полезно для «power users»

【 РЕШЕНИЕ 9: Uninstaller — чистое удаление + опция сохранить данные 】

ОБОСНУЙ:
  • Стандартное удаление NSIS удаляет:
    - Файлы приложения (Program Files или LocalAppData)
    - Ярлыки
    - Записи в реестре
  • Кастомное — добавляет страницу «Сохранить пользовательские
    данные?»
    - ✓ Сохранить настройки (config.json)
    - ✓ Сохранить стратегии (strategies/)
    - ✓ Сохранить логи (logs/)
  • Если пользователь снимает галочки — удаляем всё
  • По умолчанию — сохранить (безопаснее)

ПОЧЕМУ ВАЖНО:
  • Пользователь может переустанавливать — не хочет терять
    настройки
  • Уважение к пользовательским данным

ПОЧЕМУ ПО УМОЛЧАНИЮ СОХРАНИТЬ:
  • Удаление данных — необратимо
  • Лучше оставить лишнее, чем потерять нужное

【 РЕШЕНИЕ 10: Регистрация в реестре для «Программы и компоненты» 】

ОБОСНУЙ:
  • NSIS автоматически регистрирует установленное приложение
    в HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\
    или HKCU\...
  • Ключи:
    - DisplayName: "Zapret Manager"
    - DisplayVersion: "0.1.0"
    - Publisher: "Zapret Manager Project"
    - DisplayIcon: путь к иконке
    - UninstallString: путь к uninstaller
    - EstimatedSize: в KB
    - InstallLocation: путь установки
  • Отображение в «Приложения и возможности» с иконкой

ПОЧЕМУ ВАЖНО:
  • Пользователь может удалить через стандартный интерфейс
  • Отображение размера, версии, издателя
  • Стандарт для Windows

【 РЕШЕНИЕ 11: Проверка на уже установленную версию 】

ОБОСНУЙ:
  • При запуске установщика — проверка реестра на
    существующую установку
  • Если найдена:
    - Предложить обновление (запустить поверх)
    - Или удаление старой + установка новой
  • Обработка миграции настроек (они в %APPDATA%, не трогаются)

ПОЧЕМУ ВАЖНО:
  • Пользователь может случайно установить дважды
  • Обновление = сохранение настроек

【 РЕШЕНИЕ 12: Silent install /S для CI/CD и массовой установки 】

ОБОСНУЙ:
  • NSIS поддерживает /S для тихой установки
  • Все опции берутся из дефолтных значений
  • Полезно для:
    - Корпоративной установки
    - CI/CD автотестов
    - Автоматизации
  • Не даём пользователю галочек — всё по умолчанию

ПОЧЕМУ ВАЖНО:
  • Стандарт индустрии
  • Позволяет автоматизировать тестирование

【 РЕШЕНИЕ 13: Подпись .exe (код-сайнинг) — опционально 】

ОБОСНУЙ:
  • Без подписи Windows SmartScreen показывает:
    «Windows защитила ваш компьютер»
  • Для Open Source проекта можно получить бесплатную
    подпись через SignPath или Azure Trusted Signing
  • На этапе 17 — настраиваем pipeline для подписи
  • В production — обязательно подписывать

ПОЧЕМУ НЕ ОБЯЗАТЕЛЬНО СЕЙЧАС:
  • Требует сертификата
  • Может быть добавлено на Этапе 23 (Деплой)

РЕКОМЕНДАЦИЯ: настроить конфигурацию для подписи, но
применять её только на Этапе 23.

【 РЕШЕНИЕ 14: Мультиязычность установщика (RU + EN) 】

ОБОСНУЙ:
  • NSIS поддерживает MUI_LANGUAGE
  • Определяем язык системы через GetUserDefaultUILanguage
  • Загружаем соответствующие строки из .nsh
  • Русский и английский — основные для проекта

ПОЧЕМУ НЕ ТОЛЬКО РУССКИЙ:
  • Приложение может использоваться международно
  • Английский — стандарт

ПОЧЕМУ НЕ БОЛЬШЕ ЯЗЫКОВ:
  • На этапе 17 — только 2
  • Остальные — при необходимости

【 РЕШЕНИЕ 15: NSIS_HOOK для инициализации после установки 】

ОБОСНУЙ:
  • После установки приложения (не первого запуска) —
    выполнить NSIS_HOOK_POSTINSTALL
  • Внутри:
    - Если пользователь выбрал «Запускать при старте Windows» —
      добавить ключ в HKCU\...\Run
    - Создать ярлыки (если выбрано)
    - Открыть приложение (если выбрано)
  • Не путать с init_resources (Этап 16) — там распаковка
    стратегий

ПОЧЕМУ В NSIS, А НЕ В ПРИЛОЖЕНИИ:
  • Autostart должен работать до первого запуска
  • Ярлыки — до первого запуска
  • Приложение не должно иметь прав на создание ярлыков

【 2. src-tauri/installer/hooks.nsh 】
Назначение: основной хук установщика.

Содержимое (фрагмент):
```nsis
!macro NSIS_HOOK_PREINSTALL
  ; Проверка системы
  !insertmacro CheckWindowsVersion
  !insertmacro CheckDiskSpace
!macroend

!macro NSIS_HOOK_POSTINSTALL
  ; Автозапуск
  ${If} $AutoStart == 1
    WriteRegStr HKCU "Software\Microsoft\Windows\
      CurrentVersion\Run" "ZapretManager" "$INSTDIR\
      ZapretManager.exe"
  ${EndIf}

  ; Ярлык на рабочем столе
  ${If} $CreateDesktopShortcut == 1
    CreateShortCut "$DESKTOP\Zapret Manager.lnk" \
      "$INSTDIR\ZapretManager.exe" "" \
      "$INSTDIR\ZapretManager.exe" 0
  ${EndIf}

  ; Ярлык в меню Пуск
  ${If} $CreateStartMenuShortcut == 1
    CreateDirectory "$SMPROGRAMS\Zapret Manager"
    CreateShortCut "$SMPROGRAMS\Zapret Manager\
      Zapret Manager.lnk" "$INSTDIR\ZapretManager.exe"
    CreateShortCut "$SMPROGRAMS\Zapret Manager\
      Удалить.lnk" "$INSTDIR\uninstall.exe"
  ${EndIf}
!macroend

!macro NSIS_HOOK_PREUNINSTALL
  ; Удалить автозапуск
  DeleteRegValue HKCU "Software\Microsoft\Windows\
    CurrentVersion\Run" "ZapretManager"

  ; Спросить про пользовательские данные
  MessageBox MB_YESNO|MB_ICONQUESTION \
    "Удалить пользовательские данные (настройки, стратегии, логи)?" \
    IDYES deleteUserData IDNO skipDeleteUserData

  deleteUserData:
    RMDir /r "$APPDATA\ZapretManager"
    Goto endDeleteUserData

  skipDeleteUserData:
    DetailPrint "Пользовательские данные сохранены"

  endDeleteUserData:
!macroend

!macro NSIS_HOOK_POSTUNINSTALL
  ; Удалить ярлыки
  Delete "$DESKTOP\Zapret Manager.lnk"
  Delete "$SMPROGRAMS\Zapret Manager\*.lnk"
  RMDir "$SMPROGRAMS\Zapret Manager"

  ; Удалить папку установки
  RMDir /r "$INSTDIR"
!macroend

!macro CustomWelcomePage
  !insertmacro MUI_HEADER_TEXT \
    "Добро пожаловать в Zapret Manager" \
    "Установка займёт меньше минуты"

  ; Кастомный UI
  nsDialogs::Create 1018
  Pop $0

  ${NSD_CreateLabel} 0 0 100% 40u \
    "Zapret Manager — приложение для управления стратегиями$\r$\n\
    обхода блокировок Discord, YouTube и Outlast Trials."
  Pop $1

  ${NSD_CreateLabel} 0 50u 100% 100u \
    "Что будет установлено:$\r$\n\
    ✓ 7 встроенных стратегий обхода$\r$\n\
    ✓ winws.exe и WinDivert$\r$\n\
    ✓ Поддержка Outlast Trials$\r$\n\
    ✓ Переключение на VPN"
  Pop $2

  nsDialogs::Show
!macroend
```

Требования:
  • Все макросы с префиксом NSIS_HOOK_
  • Кастомные переменные ($AutoStart, $CreateDesktopShortcut)
    объявляются в начале
  • Проверки системы — до установки

ГИПОТЕЗА 1: Bitmap'ы не отображаются в NSIS
  ПРИЧИНА: неправильный формат (PNG вместо BMP) или
    размер.
  ЧТО ПРОВЕРИТЬ: welcome.bmp — 164x314 px, 24-bit BMP.
    header.bmp — 150x57 px, 24-bit BMP.

ГИПОТЕЗА 2: Кастомные страницы не появляются
  ПРИЧИНА: хуки не подключены или template не заменён.
  ЧТО ПРОВЕРИТЬ: installerHooks путь корректен.
    Макросы вызваны в правильном порядке.

ГИПОТЕЗА 3: Установка падает с ошибкой UAC
  ПРИЧИНА: perMachine выбран без admin-прав.
  ЧТО ПРОВЕРИТЬ: RequestExecutionLevel admin для
    perMachine, user для currentUser.

ГИПОТЕЗА 4: Кириллица в установщике — кракозябры
  ПРИЧИНА: отсутствует Unicode true.
  ЧТО ПРОВЕРИТЬ: в .nsi файле Unicode true в начале.

ГИПОТЕЗА 5: Ярлыки не создаются
  ПРИЧИНА: переменные $CreateDesktopShortcut не
    заполнены (остаются 0).
  ЧТО ПРОВЕРИТЬ: nsDialogs правильно инициализированы.
    ${NSD_GetState} после nsDialogs::Show.

ГИПОТЕЗА 6: Автозапуск не работает
  ПРИЧИНА: реестр не записан или путь неправильный.
  ЧТО ПРОВЕРИТЬ: HKCU\...\Run\ZapretManager = "$INSTDIR\
    ZapretManager.exe". Проверить в regedit.

ГИПОТЕЗА 7: Удаление оставляет файлы
  ПРИЧИНА: файлы заблокированы или RMDir не сработал.
  ЧТО ПРОВЕРИТЬ: в NSIS_HOOK_POSTUNINSTALL правильные
    пути.

ГИПОТЕЗА 8: Установщик не запускается на Windows 10
  ПРИЧИНА: несовместимые API или .NET dependency.
  ЧТО ПРОВЕРИТЬ: тестировать на реальной Win 10.
    NSIS-скрипты должны работать без зависимостей.

ГИПОТЕЗА 9: Обновление поверх старой версии падает
  ПРИЧИНА: файлы заняты запущенным приложением.
  ЧТО ПРОВЕРИТЬ: NSIS должен закрыть процессы с
    ZapretManager.exe через FindWindow + SendMessage WM_CLOSE
    или taskkill.

ГИПОТЕЗА 10: Размер установщика > 100 MB
  ПРИЧИНА: LZMA отключен или ресурсы не сжаты.
  ЧТО ПРОВЕРИТЬ: compression: "lzma".

ГИПОТЕЗА 11: Silent install (/S) не работает
  ПРИЧИНА: страницы требуют ввода.
  ЧТО ПРОВЕРИТЬ: SilentInstall silent в .nsi. Все
    значения по умолчанию установлены.

ГИПОТЕЗА 12: Кастомные bitmap'ы выглядят пиксельно
  ПРИЧИНА: неправильный DPI или размер.
  ЧТО ПРОВЕРИТЬ: exactly 164x314 и 150x57. Не
    использовать scale.
