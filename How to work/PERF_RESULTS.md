| Область | Изменение | Эффект |

| Модалки | `LicensesModal` грузится по клику | модалка вне стартового трафика |
| Skeleton | `components/shared/PageSkeleton.tsx` | заглушка вместо пустого экрана при загрузке чанка |
| Карточки | `StrategyGameCardItem` + `memo`, стабильные колбэки через `useCallback` | карточка перерисовывается только при смене своей стратегии |

| Логи | `memo` для `LogRow` (был раньше), флаш батча переведён на `requestIdleCallback` с таймаутом 100 мс | нет setState в середине кадра |

## Откат изменений, которые не понадобились

- `useShallow` в селекторах логов: не добавлен. Селекторы возвращают уже
  готовые ссылки на массивы стора, а производные значения считаются в
  `useMemo`; `useShallow` здесь не меняет количество ререндеров.
- Импорт иконок поштучно из `lucide-react/icons/*`: не нужен, rolldown
  вырезает неиспользуемые иконки — отдельные чанки иконок в сборке
  появляются только для динамических импортов.
- `requestIdleCallback` в логах оставлен, но с `timeout: 100 мс`, чтобы
  батч гарантированно уходил даже если браузер никогда не отдаёт idle.

## Что не проверено

- Профилировщики Chrome DevTools (Performance, Memory, heap snapshots) и
  React DevTools Profiler: расширений нет в WebView2.
- `cargo flamegraph`: нет `perf`, Rust-часть не менялась и не является
  узким местом по замерам CPU.
- Истинные 60 FPS на слабом железе: измерялось на одном компьютере;
  сценарий low-tier (`useDeviceTier`) проверен только чтением кода.
- Нагрузка при активной стратегии (реальный обход блокировок) и при
  10 000 логов, приходящих потоком от Rust: замерен только сценарий
  разом добавленных 10 000 логов через моки.
