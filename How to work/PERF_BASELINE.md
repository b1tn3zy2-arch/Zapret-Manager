## Что показал осмотр кода до правок

| Проблема | Где | Следствие |
|---|---|---|
| Все 6 страниц в главном чанке | `app/App.tsx` | 136,8 КБ gzip грузится до первого кадра |
| `LicensesModal` в бандле Настроек | `components/settings/AboutSection.tsx` | модалка с лицензиями в стартовом трафике |
| Колбэки карточек создаются на каждый рендер | `StrategyCollection.tsx` | `memo` не даёт эффекта, карточки перерисовываются целиком |
| Инлайновые `onSelect` в сайдбаре | `Sidebar.tsx` | `memo` для пунктов меню невозможен |
| `Dashboard` перерисовывается каждую секунду | `pages/Dashboard.tsx` + `useUptime` | виджеты статистики, пинга и логов пересоздаются из-за секундного тика uptime |
| `getBoundingClientRect()` на каждый `mousemove` | `useCardTilt.ts` | принудительный layout на каждом событии мыши |
| `setInterval` для флаша логов | `stores/useLogsStore.ts` | флаш в момент занятости кадра вместо idle |
| `useMediaQuery` без потребителей | `hooks/useMediaQuery.ts` | мёртвый модуль |

## Чего не смогли снять baseline

- Профиль React DevTools и Chrome DevTools Performance/Memory — расширения
  DevTools нет в WebView2.
- Heap snapshots — нет доступа к DevTools, вместо них использован
  собственный счётчик `performance.memory` в dev-оверлее.
- `cargo flamegraph` — нет perf/speedscope, профилирование Rust не требуется:
  горячие пути уже батчатся (см. чек-лист этапа 20).
