🎨 UI-Киты для VPN-Приложений
Эти наборы помогут быстро создать интерфейс в нужной эстетике.

SkyVPN

Что это: Минималистичный UI-кит для VPN-приложений, выполненный в тёмной эстетике. Включает всё необходимое для создания качественного интерфейса.

Формат: Figma.

Лицензия: Бесплатно.

Ссылка: SkyVPN на Muzli

VPN Mobile App UI Kit

Что это: Набор из 54 экранов с поддержкой светлой и тёмной темы. Покрывает онбординг, выбор сервера, дашборд подключения и настройки. 3 экрана предоставляются бесплатно.

Формат: Figma.

Лицензия: Бесплатно (частично, 3 экрана).

Ссылка: VPN Mobile App UI Kit на Figma

VPNite

Что это: Современный и детализированный UI-кит для VPN-приложения, который легко редактировать под свои нужды.

Формат: Figma.

Лицензия: Бесплатно.

Ссылка: VPNite на Codeintra

🛡️ Иконки «Щит» и «Безопасность»
Для главной иконки, логотипа и состояний трея.

Security Shield (Core Neon)

Что это: Иконка щита из коллекции Core Neon от Streamline. Это минималистичный стиль, который отлично читается в маленьком размере (для трея).

Формат: SVG, PNG.

Лицензия: Бесплатно (с указанием авторства).

Ссылка: Security Shield на Streamline

SecureKey Shield

Что это: Векторная иконка, объединяющая щит и замочную скважину. Выполнена в неоново-зелёном цвете, что полностью совпадает с палитрой вашего проекта.

Формат: SVG, AI, PDF, PNG.

Лицензия: Бесплатно.

Ссылка: SecureKey Shield на Logowik

Shield Check (Core Neon)

Что это: Иконка щита с галочкой — идеальный вариант для состояния connected (активно) в вашем трее. Также из коллекции Core Neon.

Формат: SVG, PNG.

Лицензия: Бесплатно (с указанием авторства).

Ссылка: Shield Check на Proicons

💡 Рекомендации по Сборке
Интерфейс: Возьмите за основу SkyVPN или VPNite. Они оба в тёмной теме и зададут правильный тон.

Главная иконка: Используйте SecureKey Shield. Он уже в неоново-зелёном цвете, вам останется только добавить молнию и свечение.

Иконки трея: Для состояний idle и connected отлично подойдут Security Shield и Shield Check из набора Core Neon. Они минималистичны и будут читаемы на 16x16.

Эти бесплатные ресурсы дадут вам прочную основу, которую вы сможете адаптировать под уникальный стиль Zapret Manager.
