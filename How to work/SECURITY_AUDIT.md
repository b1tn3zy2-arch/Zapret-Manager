## 1. Проверенные векторы

| # | Вектор | Метод проверки | Результат |
|---|---|---|---|
| 1 | Path traversal через `scan_strategies` / `run_strategy` | Чтение кода, тесты `safe_path` | Найдена проблема: `run_strategy` принимал произвольный путь от frontend. Исправлено: файл должен лежать в последней просканированной папке, `canonicalize` обязателен |
| 2 | Command injection через `cmd.exe /c` | Эксперимент с cmd на машине, тесты `escape_for_cmd` | Найдена проблема: пути подставлялись в строку команды без проверки, `%VAR%` расширялся. Исправлено: запрет `%`, `!`, кавычек и управляющих символов, аргументы в кавычках |

| 4 | Symlink в папке стратегий | Тест `safe_path_rejects_symlink_escape` | Закрыто через `canonicalize` и сравнение префиксов |
| 5 | Запись произвольных файлов из frontend (fs-плагин) | Аудит capabilities и вызовов | Убран доступ fs к произвольным путям: чтение и запись идут через `read_user_text_file` / `write_user_text_file` с проверкой расширения и лимита 1 МБ |

## 2. Найденные и исправленные проблемы

| # | Проблема | Серьёзность | Исправление |
|---|---|---|---|
| S1 | `run_strategy` запускал любой `.bat`, переданный из frontend, с правами администратора | Высокая | Путь сверяется с последней просканированной папкой, допускаются только `.bat`/`.cmd` |
| S2 | Пути подставлялись в строку `cmd.exe /c` без экранирования | Высокая | `escape_for_cmd` + запрет символов, которые cmd.exe расширяет |
| S3 | `strategy_id` шёл в имя файла лога и в команду без проверки | Средняя | Строгая валидация id |
| S4 | Frontend читал и писал произвольные пути через fs-плагин | Средняя | Заменено на Rust-команды с лимитами и проверкой расширения |
| S5 | `shell:allow-execute` в capabilities, хотя фронтенд не запускает процессы | Средняя | Разрешение удалено |
| S6 | `updater_download` принимал произвольный URL | Средняя | Whitelist доменов и лимит размера |
| S7 | Содержимое VPN-конфига могло попасть в логи | Низкая | Логируется только имя, буфер обнуляется |
| S8 | `expect` в статических регулярных выражениях | Низкая | Fail-closed инициализация без паник |
| S9 | `devtools` не отключались явно | Низкая | `devtools: false` |
