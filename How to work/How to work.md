【 ✅ TYPE SAFETY (TypeScript) 】
  • No any — нигде
  • No implicit any
  • useRef<THREE.Mesh>(null) — generic не забыт
  • Все пропсы компонентов типизированы через interface
  • Event handlers типизированы (React.MouseEvent<HTMLButtonElement>)
  • Возвращаемые типы функций явные, если не очевидны
  • Union-типы вместо boolean-флагов где возможно

【 ✅ TYPE SAFETY (Rust) 】
  • Result<T, E> для всех fallible операций
  • No unwrap() без комментария-обоснования
  • No panic! в production-коде
  • Custom error types через thiserror
  • Нет .clone() без необходимости
  • Все pub-структуры с derive(Debug, Serialize, Deserialize)

【 ✅ MEMORY / LEAKS 】
  • dispose() для geometry/material/texture (Three.js)
  • cleanup в useEffect (removeEventListener, cancelAnimation)
  • AbortController для fetch при unmount
  • Отписка от Tauri listen() при unmount
  • Нет циклических ссылок
  • Нет подписок без отписки

【 ✅ SSR / RSC (если применимо) 】
  • dynamic import с ssr: false для Canvas
  • Нет window/document на верхнем уровне
  • useIsomorphicLayoutEffect вместо useLayoutEffect
  (Для Tauri-приложения это менее актуально, но принцип верен)

【 ✅ REACT BEST PRACTICES 】
  • НЕТ useState в useFrame / animation loop
  • useRef для мутаций, не useState
  • useMemo для тяжёлых вычислений
  • useCallback для стабильных ссылок
  • Нет лишних ре-рендеров (проверить React DevTools Profiler)
  • Ключи в списках — стабильные, не index
  • Компоненты не мутируют пропсы

【 ✅ RUST BEST PRACTICES 】

  • Обработка ошибок через Result
