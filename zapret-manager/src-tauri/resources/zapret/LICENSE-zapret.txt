NOTICE для пользователей Zapret Manager

Проект Zapret Manager распространяет встроенные ресурсы zapret, полученные из
репозитория bol-van/zapret и из сборки Flowseal/zapret-discord-youtube.

  Источник:   https://github.com/bol-van/zapret
  Сборка:     https://github.com/Flowseal/zapret-discord-youtube
  Версия:     1.10.3

В бандл входят:

  winws.exe, WinDivert.dll, WinDivert64.sys — компоненты zapret, лицензия MIT
  cygwin1.dll — компонент Cygwin, лицензия LGPL
  stun.bin, stun2.bin, quic_initial_*.bin, tls_clienthello_*.bin,
  ACTIVE_*.bin — шаблоны zapret
  list-*.txt, ipset-*.txt — списки zapret
  general-*.bat, service.bat — скрипты zapret, содержимое не изменялось,
  переименованы только имена файлов

Лицензии отдельных компонентов:

  zapret, winws, шаблоны .bin — MIT (см. выше)
  WinDivert — GPL v3 или MIT, выбирает пользователь
  Cygwin (cygwin1.dll) — LGPL v3 с исключением статической линковки

Полные тексты лицензий доступны внутри приложения: «Настройки → О
приложении → Лицензии».
