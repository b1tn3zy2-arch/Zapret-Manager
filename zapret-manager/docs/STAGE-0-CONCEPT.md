## 2. Позиционирование

**Zapret Manager** — десктопное приложение для Windows,
превращающее набор `.bat`-скриптов zapret в управляемый
продукт: сканирование, запуск в один клик, живые логи,
визуализация трафика, переключение на VPN, автообновление.

**Не позиционируется как:** обход блокировок «из коробки
для всех». Пользователь всё равно выбирает стратегию —
приложение делает выбор понятным и быстрым.

**Ключевая ценность:** пользователь, который не понимает
DPI, `--dpi-desync` и `winws.exe`, всё равно может
запустить рабочий обход и понять, что происходит.

## 3. Целевая аудитория

**Основная — обычный пользователь, не технарь.**

- Не читает документацию winws
- Хочет одну кнопку «Подключиться»
- Не понимает, почему «иногда работает, иногда нет»
- Ценит, что приложение объясняет состояние

**Вторичная — продвинутый пользователь.**

- Хочет выбрать конкретную стратегию из коллекции
- Смотрит логи, добавляет свои домены
- Импортирует свои VPN-конфиги

**Следствие для UI:** простое действие по умолчанию,
продвинутое доступно рядом, но не мешает. Технические
детали — в панели «Для продвинутых», а не в первом экране.

## 4. Сигнатурные моменты (два)

### 4.1 Игра в стратегии — коллекция карт

Стратегии показываются не списком строк, а картами с
характеристиками: сложность, стабильность, покрытие,
редкость. Карта переворачивается по клику, реагирует на
курсор 3D-наклоном, у активной карты неоновое свечение.

**Почему это работает:** превращает рутинный выбор
`.bat`-файла в осмысленный выбор «какая карта лучше».
Пользователь запоминает интерфейс, а не список файлов.

**Ключевое отличие от документа:** редкость считается не
по числу сервисов, а по score из техник обхода
(`faketls`, `multisplit`, `quic-fake`, `l7-filter`,
`ipset`, `any-protocol`, `cutoff`). Иначе все 22 карты
стали бы Common — они бы не различались вообще.

### 4.2 Визуализатор трафика — приборная панель

Живые графики входящего и исходящего трафика, пинг до
сервисов, счётчики соединений и состояние обхода.
Выглядит как панель управления, а не как дашборд
с бубликами.

**Почему это важно:** главный вопрос пользователя —
«работает обход или нет». График трафика отвечает на
него визуально, без чтения логов.

## 5. Outlast Trials — решение

Игра использует BattlEye и серверы GameLift. Точные
домены игровых серверов непубличны и выдаются
динамически.

**Что есть в архиве:** вместо доменного фильтра
используется Game Filter по диапазонам портов
(`GameFilterTCP` / `GameFilterUDP`, по умолчанию
`1024-65535`) и фейковый шаблон `ACTIVE_GAME_UDP.bin`.
Ни одного упоминания Outlast в репозитории нет.

**Решение:**

1. Основной механизм — Game Filter по портам, он уже
   реализован в zapret и работает.
2. Дополнительно — редактируемый список доменов в
   настройках: пользователь добавляет то, что знает.
3. Стартовый набор доменов (Steam, Epic, BattlEye,
   GameLift, AWS) — как разумное значение по умолчанию
   с честной пометкой «список приблизительный».
4. Полный автоматический захват доменов из сетевого
   трафика — вне области MVP. Требует снифера.

**Честно перед пользователем:** в UI домены помечены как
«стартовый набор», а не как «точный список серверов».

## 6. Переключение bat ↔ VPN — решение

**Провайдеры:** WireGuard и AmneziaWG через `.conf`.
Оба используют один формат конфига и совместимы с
официальным клиентом WireGuard for Windows.

**Почему не другие:**

- **Amnezia VPN** — Electron-приложение, тяжёлое,
  ориентировано на self-hosted серверы
- **OpenVPN** — в 2–3 раза медленнее, устарел
- **Xray/VLESS** — требует настройки сервера вручную

**Критичное требование:** режимы взаимоисключающие.
WinDivert (zapret) и WFP (WireGuard) конфликтуют на
уровне сетевого стека. Переключение — только последовательно:
сначала остановить текущий режим, дождаться, потом
запускать новый.

**VPN-сервер не нужен** — пользователь импортирует свой
`.conf` через настройки.

## 9. Критерии успеха

Измеримые, без «на глаз».

| Метрика                   | Цель                               |
| ------------------------- | ---------------------------------- |
| Холодный старт            | < 2 сек                            |
| FPS                       | ≥ 60 на десктопе, ≥ 30 на ноутбуке |
| RAM                       | < 200 MB                           |
| Сканирование 50 стратегий | < 500 мс                           |
| Логи                      | 10 000 строк при 60 FPS            |
| Установщик                | 30–50 МБ (с ресурсами)             |
| Установка                 | < 15 сек                           |
| Консоль                   | ноль ошибок и предупреждений       |
| Возраст ОС                | Windows 10 1809+ и Windows 11      |
| Утечки памяти             | рост heap < 20 МБ за 30 минут      |

**Функциональные критерии:**

- После Stop не остаётся процессов `winws.exe`
- После закрытия приложения не остаётся процессов `winws.exe`
- Все 22 стратегии запускаются из приложения
- Карты имеют разную редкость
- Пользовательские домены переживают обновление стратегий
- Установщик удаляется без следов

## 11. Что НЕ входит в MVP

Явные границы, чтобы не расползался объём:

- Автоматический захват доменов из трафика (нужен снифер)
- Мобильные и macOS-версии
- Расширенная аналитика и телеметрия
- Плагины и пользовательские скрипты
- Полная локализация (только базовая RU/EN)
- Светлая тема (тёмная + авто)
- Собственный сервер обновлений
- Собственный VPN-сервер
