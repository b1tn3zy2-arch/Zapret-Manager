# БЕЗОПАСНОСТЬ ZAPRET MANAGER

Документ описывает модель угроз, принятые защитные меры и то, что
намеренно остаётся вне зоны ответственности приложения.

Дата аудита: 2026-10-07 (этап 21).

## 1. Модель угроз (STRIDE)

| Категория              | Актуально для проекта                                               | Меры                                                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spoofing               | Подмена ресурсов zapret, подмена обновлений, подмена приложения     | SHA-256 манифест ресурсов, HTTPS-only и whitelist доменов для загрузок, подпись установщика (этап 17)                                                      |
| Tampering              | Правка `config.json`, `.bat`, `list-*.txt`, подмена файлов в bundle | Проверка целостности ресурсов, `canonicalize` + проверка базовой папки, размеры файлов, запрет символов `%` и `!` в путях для cmd.exe                      |
| Repudiation            | Недостаток следов действий                                          | Отдельный `security.log` с ротацией, все критичные отказы логируются с таргетом `security`                                                                 |
| Information disclosure | Утечка ключей VPN, токенов, лишних данных в логах                   | `sanitize_log_message` скрывает `PrivateKey`, `password`, `token` и подобное; содержимое `.conf` не логируется; буферы конфигов обнуляются через `zeroize` |
| Denial of Service      | Огромные файлы, поток логов, частые IPC-вызовы                      | Лимиты размеров (1 МБ текст, 100 КБ `.conf`, 200 МБ архив, 50 МБ ресурс), лимит логов 10 000 строк, rate limit на критичных командах                       |
| Elevation of privilege | Запуск произвольного кода с правами администратора                  | Стратегия запускается только из последней просканированной папки, только `.bat`/`.cmd`, id стратегии по строгому шаблону, экранирование аргументов cmd.exe |

## 2. Активы

1. Файловая система пользователя: папка стратегий, `%APPDATA%\com.zapretmanager.app`.
2. Процессы ОС: запускается только `winws.exe` из комплекта стратегии.
3. Настройки: `config.json` и бэкапы.
4. VPN-конфиги: `.conf` с приватными ключами.
5. Логи приложения и журнал безопасности.

## 3. Вне области защиты

- Компрометация ОС или учётной записи администратора.
- Физический доступ к машине.
- Вредоносный `.bat`, который пользователь сам запустил из своей папки:
  это основная функция приложения, и она требует повышенных прав.
- Атаки на ядро Windows и на сам WebView2.

## 4. Реализованные защиты

### Rust: модуль `security`

| Модуль             | Что делает                                                                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `paths.rs`         | `safe_path` (canonicalize + проверка базовой папки), `safe_filename`, `validate_strategy_id`, `validate_strategy_file`                                                     |
| `sanitize.rs`      | `escape_for_cmd`, `ensure_cmd_safe_value`, `sanitize_log_message`, `validate_domain`, `validate_port`, `validate_ip`, `validate_ip_range`                                  |
| `rate_limit.rs`    | `RateLimiter` и лимиты: 10 запусков стратегии в минуту, 1 установка обновления в 5 минут, 5 переключений VPN в минуту, 20 инъекций в минуту, 60 файловых операций в минуту |
| `url_validator.rs` | `validate_https_url`, `validate_host` со списком разрешённых доменов, `is_public_host` для открытия ссылок                                                                 |
| `mod.rs`           | Лимиты размеров, `security_event`, `security_denied`, путь к журналу безопасности                                                                                          |

### Критичные команды

| Команда                                       | Проверки                                                                                                                     |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `run_strategy`                                | валидный id, rate limit, `.bat`/`.cmd` только, файл внутри последней просканированной папки, экранирование путей для cmd.exe |
| `stop_strategy`, `check_strategy_status`      | валидный id                                                                                                                  |
| `scan_strategies`                             | папка должна существовать, запоминается как доверенная база                                                                  |
| `inject_outlast`                              | валидация каждого домена и каждого CIDR, rate limit, валидация пути к `.bat`                                                 |
| `switch_to_vpn`                               | rate limit, проверка id конфига                                                                                              |
| `import_vpn_config`                           | лимит 100 КБ, безопасное имя файла, обнуление буфера через `zeroize`, содержимое не логируется                               |
| `download_update`                             | только https и whitelist доменов, лимит 200 МБ, rate limit на установку                                                      |
| `install_update`                              | rate limit 1 в 5 минут, проверка версии, лимит архива                                                                        |
| `read_user_text_file`, `write_user_text_file` | абсолютный путь, только `.txt`, `.json`, `.conf`, `.log`, лимит 1 МБ, rate limit                                             |
| `open_external_url`                           | только https, без логина и пароля, запрет локальных и приватных адресов                                                      |

### WebView и Tauri

- CSP: `default-src 'self'`, `script-src 'self'` без `unsafe-inline`,
  `object-src 'none'`, `frame-src 'none'`, `frame-ancestors 'none'`,
  `base-uri 'none'`, `form-action 'none'`.
- `devtools: false` — инструменты разработчика отключены во всех сборках.
- `capabilities/default.json` — 31 разрешение, без wildcard. Убраны
  `shell:allow-execute`, `shell:allow-open`, `updater:default`,
  `notification:default`, `process:allow-restart`, `opener:default`.
- Файлы и внешние ссылки frontend больше не открывает сам: только через
  Rust-команды с валидацией.

### Frontend

- `lib/sanitize.ts` — валидаторы домена, порта, IP, CIDR, пути и версии,
  редактирование HTML, скрытие секретов в сообщениях.
- `lib/secureInvoke.ts` — единая точка вызова IPC с нормализацией ошибок
  и проверкой ответов по схемам.
- `types/ipcSchemas.ts` — Zod-схемы со `.strict()` для данных из Rust
  и из сети.
- ESLint: `no-eval`, `no-implied-eval`, `no-new-func`, `no-script-url`,
  запрет `console.log`.
- В коде нет `dangerouslySetInnerHTML`, `eval` и `innerHTML`.

### Журнал безопасности

- События с таргетом `security` пишутся в
  `%APPDATA%\com.zapretmanager.app\logs\security.log`.
- Файл создаётся при первом событии, ротация на 1 МБ с сохранением
  предыдущей версии как `security.log.1`.
- Файл никуда не отправляется.

## 5. Проверки

```bash
node scripts/security-audit.mjs   # опасные конструкции, capabilities, CSP
pnpm exec tsc --noEmit            # типы
pnpm exec eslint .                # линтер
cargo test --manifest-path src-tauri/Cargo.toml

cargo audit                       # уязвимости Rust (нужен cargo-audit)
```

## 6. Политика обновлений безопасности

1. Обновления стратегий приходят только по HTTPS с GitHub Releases,
   домен в белом списке, архив распаковывается во временную папку и
   устанавливается с предварительным бэкапом.
2. Целостность файлов ресурсов проверяется по `manifest.json` (SHA-256).
3. Исправления безопасности выходят тем же каналом, что и обычные
   обновления, и не требуют ручной установки файлов.

## 7. Как сообщить об уязвимости

Приложение распространяется без опубликованного репозитория с
issue-трекером. Сообщение следует направить автору проекта
Zapret Manager Project вместе с:

- версией приложения (Настройки → О приложении);
- шагами воспроизведения;
- выводом из `security.log`, если он есть.

Ответ по безопасности ожидается в течение 7 дней, исправление —
в ближайшем обновлении ресурсов.
