# Установка и обновление

## Системные требования

| Параметр         | Значение                                                                      |
| ---------------- | ----------------------------------------------------------------------------- |
| ОС               | Windows 10 версии 1809 (build 17763) или новее, Windows 11                    |
| Архитектура      | x64                                                                           |
| Свободное место  | ~200 MB (приложение + драйверы WinDivert + ресурсы)                           |
| WebView2 Runtime | предустановлен в Windows 11; в Windows 10 ставится отдельно с сайта Microsoft |
| Права            | стандартные; UAC запрашивается только при запуске стратегии                   |

## Варианты установки

### NSIS-установщик (рекомендуется)

`ZapretManager_<версия>_x64-setup.exe`

- Тёмная тема, выбор языка (русский/английский), выбор режима установки (для пользователя или для всех)
- Ярлыки в меню «Пуск» и на рабочем столе
- Удаление через «Параметры → Приложения» или через установщик

### MSI-пакет

`Zapret Manager_<версия>_x64_ru-RU.msi`

- Нужен для централизованного развёртывания (Group Policy, SCCM)
- Собирается в локализации ru-RU: WiX 3.x не умеет объединять базы 1251 и 1252 в одном MSI,
  поэтому английская установка доступна через двуязычный NSIS-установщик выше

### Portable-версия

`ZapretManager_<версия>_x64_portable.zip`

- Распакуйте в любую папку и запустите `zapret-manager.exe`
- Не создаёт ярлыков и записей в реестре; удаление — удаление папки

## Проверка целостности

В каждый релиз входит `SHA256SUMS.txt`.

```powershell
# Windows
certutil -hashfile "ZapretManager_0.1.0_x64-setup.exe" SHA256
```

```bash
# Linux / macOS / Git Bash
sha256sum -c SHA256SUMS.txt
```

Сравните полученный хеш с соответствующей строкей файла. Расхождение означает, что файл повреждён
или подменён — не запускайте его.

## Обновление

### Через приложение

1. «Настройки» → «Обновления» → «Проверить обновления»
2. Если доступна новая версия стратегий или приложения — «Подробности», затем загрузка и установка
3. Перед заменой создаётся бэкап: откат доступен в том же разделе

### Вручную

1. Скачайте новый установщик из [Releases](https://github.com/Flowseal/zapret-discord-youtube/releases/latest)
2. Запустите установщик поверх старой версии
3. Если менялась папка со стратегиями, проверьте «Настройки» → «Стратегии» → «Обновить»

## Удаление

1. «Параметры» → «Приложения» → «Zapret Manager» → «Удалить»
2. Установщик спросит, удалять ли пользовательские данные (`%APPDATA%\ZapretManager`)

Удаление программы оставляет драйверы WinDivert, если они были установлены отдельным
компонентом. При полной очистке проверьте `%APPDATA%\ZapretManager` вручную.

## Первый запуск

1. Приложение распаковывает встроенные ресурсы (стратегии, конфиги, движок `winws.exe`)
2. Показывается окно «Добро пожаловать» со списком распакованного
3. По умолчанию используется встроенная папка стратегий; свою можно выбрать в «Стратегии» → «Выбрать папку»

## Частые проблемы

| Симптом                              | Причина и решение                                                                                   |
| ------------------------------------ | --------------------------------------------------------------------------------------------------- |
| Установщик не запускается            | Проверьте контрольную сумму, отключите SmartScreen-проверку антивируса, запустите от администратора |
| «Приложение не отвечает» при запуске | Проверьте, установлен ли WebView2 Runtime                                                           |
| Стратегия не стартует                | Требуется подтверждение UAC; проверьте, что папка стратегий доступна на чтение                      |
| Драйвер WinDivert не загружается     | Закройте другие программы, использующие перехват трафика; перезагрузите систему после установки     |
| Трей не появляется                   | Проверьте «Настройки» → «Общие» → сворачивать в трей; значок может быть в скрытых значках           |
| VPN не подключается                  | Требуется установленный WireGuard; проверьте путь к исполняемому файлу в настройках VPN             |
